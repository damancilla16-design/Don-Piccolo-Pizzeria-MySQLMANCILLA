Sistema de Control de Inventario - Pizzería Don Piccolo 🍕Este repositorio contiene la solución completa en SQL para la prueba técnica de base de datos de la pizzería Don Piccolo. El objetivo del módulo es modelar, consultar y automatizar el inventario de ingredientes clave para prevenir la escasez de insumos.📋 Tabla de ContenidosDescripción del ProyectoEstructura del Modelo de DatosLógica de Automatización (Triggers)Vistas y Consultas ClaveInstrucciones de EjecuciónAutor📌 Descripción del ProyectoEl sistema está diseñado para:Registrar ingredientes e insumos con sus niveles de stock actual y crítico (mínimo).Controlar las entradas y salidas de inventario mediante historial de movimientos.Automatizar la actualización del stock actual usando triggers.Monitorear niveles críticos a través de vistas y consultas optimizadas.🗄️ Estructura del Modelo de DatosEl modelo consta de dos tablas relacionales enlazadas por clave foránea:+------------------------+             +--------------------------+
|      ingredientes      |             |  movimientos_ingrediente |
+------------------------+             +--------------------------+
| PK  id_ingrediente     |<-----------1| PK  id_movimiento        |
|     nombre (UNIQUE)    |            N| FK  id_ingrediente       |
|     unidad_medida      |             |     tipo (ENTRADA/SALIDA)|
|     stock_actual       |             |     cantidad             |
|     stock_minimo       |             |     fecha_movimiento     |
+------------------------+             +--------------------------+
Tablas:ingredientes: Almacena el catálogo de insumos, unidad de medida, stock actual y el nivel mínimo permitido.movimientos_ingrediente: Histórico de transacciones de 'ENTRADA' o 'SALIDA' referenciadas a cada ingrediente.⚙️ Lógica de Automatización (Triggers)actualizar_stock_ingredienteTrigger configurado de tipo AFTER INSERT sobre la tabla movimientos_ingrediente. Cada vez que se registra una transacción:Si el tipo es ENTRADA: Suma automáticamente la cantidad ingresada al stock_actual del ingrediente.Si el tipo es SALIDA: Resta automáticamente la cantidad despachada del stock_actual del ingrediente.📊 Vistas y Consultas Clave1. Vista de Resumen de Inventario (vista_resumen_inventario)Genera un análisis comparativo que calcula la diferencia en vivo entre el stock actual y el mínimo requerido:
$$\text{Diferencia} = \text{stock\_actual} - \text{stock\_minimo}$$
Ordena los resultados de menor a mayor margen para detectar prioridades de reabastecimiento.2. Consulta de Ingredientes con Bajo StockFiltra los insumos críticos cuyo stock_actual < stock_minimo, ordenando en forma ascendente por el nivel disponible.3. Consulta de Movimientos RecientesUtiliza INNER JOIN para presentar los últimos 5 movimientos registrados en la base de datos junto con el nombre del ingrediente asociado.🚀 Instrucciones de EjecuciónAbre tu cliente de base de datos preferido (MySQL Workbench, phpMyAdmin, DBeaver, etc.).Abre un nuevo script SQL o consola de comandos.Importa o pega el archivo DAVIDMANCILLAEXAMENPICCOLO.sql.Ejecuta todo el script.
